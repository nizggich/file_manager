🗂️**commander** — минималистичный двухпанельный файловый менеджер в стиле Midnight Commander, написанный на чистом C с использованием библиотеки ncurses. Идеально подходит для работы в терминале, навигации по файловой системе.

✨**Возможности**
| Функции | Описание |
|---------|----------|
| 🪟 Двухпанельный интерфейс    |       Одновременная работа с двумя директориями, как в классических FM        |
| 🎨 Цветовой интерфейс         |       Поддержка цветов через ncurses, выделение активной панели и выбранного элемента  |
| 📁 Навигация по ФС            |  	    Вход в директорию (Enter), возврат назад (Backspace), прокрутка списков        |
| 🔀 Переключение панелей       |       Быстрое переключение между панелями клавишей Tab       |
| 🗂️ Сортировка                 |       Автоматическая сортировка: сначала директории, затем файлы (по алфавиту)        |
| 🔍 Классификация файлов       |       Определение типа: директория, исполняемый файл, скрипт, бинарник, текст       |
| ⌨️ Управление с клавиатуры    | 		 Полностью клавиатурный интерфейс без мыши


🎮**Управление**
| Клавиша | Действие |
|------|------|
|  w / s         |  Перемещение вверх / вниз по списку  |
|  Enter         |   Войти в директорию / открыть файл*  |
|  Backspace    |  	Вернуться в родительскую директорию    |
|  Tab    |         Переключиться на другую панель |
| q		  |         Выйти из программы |  

*Открытие файлов реализовано с помощью vim. Встроенный редактор планируется в будущих версиях.

🔧**Ключевые модули**    
| Модуль | Отвественность |
|------|------|
|commander  |Инициализация ncurses, главный цикл, обработка нажатий      |
|fs         |Чтение директорий, stat(), классификация файлов, сортировка      |
|ui         |Отрисовка рамок, заголовков, статус-бара      |
|panel      |Структура панели, прокрутка, выделение курсора      |
|qsort      |Реализация обобщённой сортировки с компаратором      |
|utils      |Вспомогательные функции: работа с путями, строками      |

🚀**Быстрый старт**    
**Требования**    
- Компилятор gcc (или совместимый)  
- Библиотека ncurses (обычно libncursesw6-dev или ncurses-devel)  
- make (опционально, но рекомендуется)  
- ОС: Linux
```bash
# Клонировать репозиторий
git clone https://github.com/nizggich/file_manager.git
cd file_manager

# Скомпилировать
make build

# Запустить
make run

# Или сразу: сборка + запуск
make run

# Отладка с gdb
make debug
```
