Минималистичный двухпанельный файловый менеджер в стиле Midnight Commander, написанный на чистом C с использованием библиотеки ncurses. Идеально подходит для работы в терминале и навигации по файловой системе.

## ✨ Возможности

| Функция | Описание |
|:--------|:---------|
| 🪟 **Двухпанельный интерфейс** | Одновременная работа с двумя директориями, как в классических FM |
| 🎨 **Цветовой интерфейс** | Поддержка тем через `ncurses`, подсветка активной панели и курсора |
| 📁 **Навигация по ФС** | Вход (`Enter`), возврат (`Backspace`), прокрутка списков |
| 🔀 **Переключение панелей** | Мгновенный фокус между панелями через `Tab` |
| 🔍 **Классификация файлов** | Автоопределение типа: `DIR`, `EXEC`, `BIN`, `TEXT`, `SYMLINK` |
| ⌨️ **Клавиатурное управление** | Полный контроль без мыши, предсказуемые хоткеи |  

---

## 🎮 Управление

| Клавиша | Действие |
|:--------|:---------|
| `w` / `s` | Перемещение ↑ / ↓ по списку |
| `Enter` | Войти в директорию / открыть файл* |
| `Backspace` | Вернуться в родительскую директорию |
| `Tab` | Переключить активную панель |
| `q` | Безопасный выход из программы |

> 💡 `*`Открытие файлов реализовано с помощью vim. Встроенный редактор планируется в будущих версиях.

## 🏗️Архитектура проекта   
> 🧩 *«Разделяй и властвуй»* — основа поддерживаемого кода.

Проект следует **модульной структуре**, где каждый компонент инкапсулирует свою ответственность:

| Модуль | 📄 Файлы | 🎯 Задача |
|--------|----------|-----------|
| **🧠 commander** | `commander.{c,h}` | Главный цикл, обработка ввода, координация |
| **📂 fs** | `fs.{c,h}` | Чтение директорий, `stat()`, классификация, сортировка |
| **🎨 ui** | `ui.{c,h}` | Абстракция над `ncurses`: цвета, рамки, позиционирование |
| **🪟 panel** | `panel.{c,h}` | Состояние панели: курсор, скролл, выделение, фокус |
| **🔀 qsort** | `qsort.c` | Универсальная сортировка с кастомными компараторами |
| **🛠️ utils** | `utils.c` | Вспомогательные функции: пути, строки, память |

## 🚀Быстрый старт    
📋**Требования**    
- Компилятор gcc (или совместимый)  
- Библиотека ncurses (обычно libncursesw6-dev или ncurses-devel)  
- make (опционально, но рекомендуется)  
- ОС: Linux
```bash
# Клонировать репозиторий
git clone https://github.com/nizggich/file_manager.git
cd file_manager

# Скомпилировать
make build

# Запустить
make run

# Или сразу: сборка + запуск
make run

# 🐛 Отладка с GDB
make debug
```
